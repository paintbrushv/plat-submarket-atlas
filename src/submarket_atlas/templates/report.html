Methodology & Sources

Data Sources

All demographic and housing data sourced from the U.S. Census Bureau American Community Survey (ACS) 5-Year Estimates, vintages {{ earliest_year }}–{{ latest_year }}. ACS 5-year estimates provide the most reliable small-area data by pooling 60 months of survey responses.

Geographic Methodology

Analysis geographies are defined as concentric rings (1, 3, and 5 miles) centered on the property coordinates ({{ lat }}, {{ lon }}). Census tracts are included in a ring if their centroid falls within the radius. For tracts that partially overlap a ring boundary, area-weighted aggregation adjusts contributions proportionally. Demographic metrics are population-weighted — a tract with 5,000 residents counts more than one with 500.

MSA Definition

The {{ msa_label }} MSA (FIPS {{ cbsa_code }}) comprises {{ msa_county_count }}{% if state_label %} {{ state_label }}{% endif %} counties. MSA-level data is pulled directly from the Census API using the metropolitan statistical area geography.

Data Quality Notes

  • ACS estimates for small geographies carry margins of error. Trends over multiple years are more reliable than single-year point estimates.
  • The 2020 ACS vintage was affected by COVID-19 data collection disruptions. Values for 2020 should be interpreted with caution.
  • Median values (income, rent, home value, age) are approximated at the submarket level using population-weighted averages of tract medians.
